# 事项结束与取消

## 目标
单个事项可标记已结束、已取消，并在详情恢复。首页所有推荐排除手动结束/取消事项；完整行程保留记录、资料与状态标签。未设置状态的历史事项仍按原有时间规则显示。

## 决策
状态为 planned/completed/cancelled，单独 PATCH 修改，不改变计划日期或资料。普通修改事项不能重置状态。公开攻略不包含用户的实际执行状态，复制后仍为正常计划。

## 实施与验证
状态保存在现有 events.data JSON，不需要结构迁移。PATCH 单独校验成员与 version，普通 PUT 保留服务端状态。首页全部使用正常计划事项，详情状态即时更新并刷新数据。API 测试覆盖非成员拒绝、同行成员操作、版本冲突、编辑保留状态、资料不变与公开快照排除执行状态；手机测试覆盖结束、取消、刷新持久性和恢复。

完成验证：35 项单元/接口测试、Chromium 13 项、WebKit 13 项全部通过。TypeScript 与 Next.js build 通过，源码审计和 diff 检查通过。完整流程日志 `.local/event-status-final-verify.log`，最终构建 `.local/event-status-build.log`。手机截图 `.local/event-status-chromium.png` 已检查。最后避免保存响应重新打开用户已经关闭的详情。http://localhost:8790 保持运行；本次未部署生产或推送远端。
