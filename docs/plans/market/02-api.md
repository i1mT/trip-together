# 分享与复制接口

## 目标与交付
`worker/market` 分为公开读取、创建者管理、快照生成与复制四个模块。

## 完成安排
- [x] 创建者才能发布、更新、撤销，发布必须确认预览 hash。
- [x] 匿名市场搜索分页与公开预览；登录后事务复制，生成独立 ID。
- [x] publicationId + version 防止并发更新重新公开已撤销内容。
- [x] requestId 保证重复请求不产生重复行程。
- [x] 可调整出发日期，保留当地时间，拒绝夏令时不存在或歧义时间。

## 验证
API 测试覆盖权限、匿名访问、更新撤销、源删除、旧版本请求、重复复制、数据隔离。独立审核发现 UPSERT 竞态，已经改为显式首次 INSERT / 版本约束 UPDATE。日期转换共享 formatter 缓存，重复时刻按照实际 UTC 时间排序。
